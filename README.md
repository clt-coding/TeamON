# TeamON 🎮

**TeamON** is a modern web application designed to streamline esports matchmaking and team building, starting with *League of Legends*.

Built as a dedicated alternative to generic Discord servers, TeamON solves the struggle of finding the right players for a duo queue or filling the last missing spot for a tournament. It provides a structured, filter-driven environment to connect players based on specific gaming criteria.

### Key Features

* **Detailed Player Profiles:** Showcase your rank, preferred roles, experience, and spoken languages.
* **Advanced Filtering:** Easily search the database by specific positions (Top, Jungle, Mid, Bot, Support), ranks, and voice-chat preferences.
* **Dynamic Listing System:** Post custom team announcements detailing exactly who you are looking for, or browse and apply to open slots.
* **Secure Matchmaking:** Discord tags remain private until a team captain officially accepts a player's application, ensuring safe and organized communication.
